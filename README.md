# Sistema de Prediccion de Diabetes

Este proyecto es una herramienta sencilla diseñada para ayudar a las personas a entender su riesgo de diabetes. Utiliza una aplicacion web facil de usar creada con Streamlit que se conecta a un sistema de inteligencia artificial.

## ¿Como funciona?

La aplicacion muestra un formulario donde puedes ingresar datos basicos de salud, como el nivel de glucosa, la edad y el peso. Una vez que presionas el boton para predecir, la informacion se envia a un servidor que analiza los datos y devuelve una respuesta indicando si hay señales de riesgo o si los indicadores estan en rangos normales.

## ¿Cual es el objetivo?

El objetivo principal es brindar una forma rapida y accesible de obtener una estimacion inicial sobre la salud relacionada con la diabetes. Es importante recordar que esta es una herramienta informativa y siempre se recomienda consultar con un profesional de la salud para un diagnostico medico real.

## Como usar este proyecto

Si quieres ejecutar la aplicacion en tu computadora, solo necesitas tener los requisitos instalados y correr el siguiente comando en tu terminal:

```bash
streamlit run app/main.py
```
